Tag scanning ·

Targets count plants placed in the current room, not the full batch inventory. Each scan counts once, including repeated tags; this is a count check, not a tag or strain validation.

Live counters reset when you reload or open another layout; placement changes reset affected batches. Recorded tags stay in this browser for CSV export. Undo removes the latest entries from this page’s counters and saved records.

Placed batches

Select a batch and press Start scanning.

Plug in a USB keyboard scanner, select a batch, and press Start scanning. Keep the tag field focused. Tags record automatically when scanner input stops; no Enter needed. Each scan adds one plant. The completion sound plays when the batch target is reached.

Completion plays the selected song clip on this computer. Keep its volume on.

Room move records

Includes all saved rooms and batches, even unfinished batches and earlier layouts. Records are written immediately to this browser’s durable local storage and work without internet. Manual additions have no tag. Repeated scans remain separate rows. Repeated exports include the same records; use Record ID to avoid importing duplicates.

Import into Google Sheets

In Google Sheets, choose File → Import → Upload and select the CSV. Turn off “Convert text to numbers, dates, and formulas” to preserve leading zeros and long tag numbers. Import into a new sheet. This records scans for your room move; it does not submit a move to METRC.
